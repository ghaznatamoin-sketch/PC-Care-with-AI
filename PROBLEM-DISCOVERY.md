# PC Care with AI

## Assignment 01 — Problem Discovery & Problem Statement

## 1. Problem Overview

Many computer users experience slow computer performance but cannot identify the actual reason behind the problem.

A slow computer can be caused by different factors such as:

- High CPU usage
- High RAM usage
- Low storage space
- Too many startup applications
- Too many background processes
- Unnecessary applications
- System configuration issues
- Performance-related software problems
- Possible hardware-related problems

For non-technical users, identifying the exact cause can be difficult.

## 2. Current User Behavior

When a computer becomes slow, users may:

1. Restart the computer.
2. Search Google for solutions.
3. Watch YouTube tutorials.
4. Try different troubleshooting methods.
5. Ask a technical person for help.
6. Take the computer to a repair shop.

These methods can take time and may not identify the actual cause.

## 3. Target Users

PC Care with AI is designed for:

**Everyone who uses a computer.**

The product should be understandable and usable by both technical and non-technical users.

## 4. Core User Problem

The main problem is:

> Computer users often cannot identify why their computer has become slow or what action they should take to solve the problem.

## 5. Problem Statement

Non-technical computer users need a simple way to automatically check their computer, identify possible causes of slow performance, clearly explain the detected problems, and provide appropriate solutions.

## 6. Opportunity

A simple computer-care application can reduce the difficulty of troubleshooting by automatically analyzing important performance information and presenting understandable results.

## 7. Proposed Direction

The proposed product is **PC Care with AI**.

The product will follow this flow:

```text
Scan → Detect → Explain → Recommend → Fix where safely possible → Verify
```

## 8. Expected Outcome

Users should be able to understand:

- What is making the computer slow.
- What the possible cause is.
- How serious the issue may be.
- What they can safely do to improve performance.
- When professional technical help may be required.
